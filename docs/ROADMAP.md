# AuraBook — Roadmap de Desenvolvimento

## Visão geral

O desenvolvimento do AuraBook será dividido em fases.

O objetivo é construir primeiro um MVP funcional e depois evoluir para uma plataforma SaaS completa.

---

Tempo estimado: 1 semana

Objetivos:

- Definição do produto
- Arquitetura
- Modelagem do banco
- Estrutura inicial do projeto


Entregas:

✅ PRD.md

✅ DATABASE.md

✅ ARCHITECTURE.md
